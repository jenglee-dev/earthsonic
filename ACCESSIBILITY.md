## Honest Remaining Gaps & Scope Boundaries

- **Manual Screen Reader Testing Not Run:** Physical/interactive sessions with NVDA, JAWS, VoiceOver, or TalkBack, as well as Windows High Contrast (`forced-colors: active`), were not executed in this environment.
- **`jsdom` vs Browser Color Contrast:** `axe-core` tests inside Vitest (`jsdom`) skip computed CSS `color-contrast` rules; real rendered contrast was instead audited by Chromium Lighthouse (`100/100`, `0` fails on all 7 routes).
- **WebGL Canvas Fallback:** The interactive 3D Three.js globe renders visual shaders inside `<canvas>`; non-visual access depends on the paired controls (`2D Orthographic Map` SVG fallback, `Describe view` textual/spoken summary, manual coordinates form, and keyboard camera navigation).
- **Environment Tooling:** `git` CLI is not installed on `PATH` in this workspace environment, so per-step git commits could not be recorded automatically.
